# Heart Disease Prediction (Logistic Regression)

## Dataset
- Heart Disease Dataset (Kaggle – UCI)
- Target column: `target` (0 = No disease, 1 = Disease)

## Tools Used
- Python
- Pandas
- Scikit-learn

## Steps Performed
1. Load the dataset.
2. Separate features (X) and target (y).
3. Encode categorical columns using One-Hot Encoding.
4. Handle missing values using mean imputation.
5. Split data into training (80%) and testing (20%).
6. Scale features using StandardScaler.
7. Train a Logistic Regression model.
8. Predict on test data.
9. Evaluate using Accuracy, Precision, Recall, and Confusion Matrix.

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- Confusion Matrix

## Result
The Logistic Regression model successfully predicts heart disease with good accuracy and balanced performance.
